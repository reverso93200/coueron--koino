# Nouveau site de la Ville de Couëron : démonstration

Démonstration en ligne du nouveau site proposé par [Koino](https://agence-koino.com/) à la Ville de Couëron.

**Ce n'est pas le site officiel de la mairie** (le site officiel : [ville-coueron.fr](https://www.ville-coueron.fr/)). Les pages ne sont pas indexées par les moteurs de recherche.

- Adresse de la démonstration : https://reverso93200.github.io/coueron--koino/
- Version statique du thème WordPress « Ville de Couëron » (1.2.0), avec ses contenus de test (octobre-novembre 2026).
- Les formulaires (contact, écrire au maire, signaler, lettre d'information) n'envoient rien : un message l'indique. La recherche fonctionne dans le navigateur, avec les mêmes synonymes que le site (« cni », « poubelle »…).
- Les horaires « ouvert / fermé » sont calculés en direct à l'heure de Paris.
